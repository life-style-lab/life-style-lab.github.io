マウスでメニューを探して…クリックして…って、地味に時間がかかってる気がする。ショートカットキーを覚えたいけど、多すぎてどれから覚えればいいかわからない！

:::writer
ショートカットキーは全部覚える必要はありません。**毎日何十回も使う操作から5〜10個**覚えるだけで、作業の流れがかなりスムーズになりますよ。WindowsとMacの対応表で整理しますね！
:::

ショートカットキーは、キーボードの組み合わせでメニュー操作を呼び出す機能です。マウスに手を伸ばす回数が減るので、作業が速くなるだけでなく、手や肩の動きも減らせます。

この記事では、==在宅ワークでよく使うショートカットキーをWindows・Macの対応表==でまとめ、==無理なく覚えるコツ==も紹介します。

:::summary 忙しい人向け：この記事の結論
1. **まずはコピー・貼り付け・元に戻す・保存・検索の5つ**。WindowsはCtrl、MacはCommandが基本
2. **ウィンドウ切り替えとスクリーンショット**を覚えると、資料作成やWeb会議が速くなる
3. **1週間に2〜3個ずつ**、よく使う操作から覚えると定着しやすい
:::

多くの基本操作は、==WindowsのCtrlキーをMacのCommand（⌘）キーに置き換える==と同じ動きになります。WindowsのAltキーは、MacではOption（⌥）キーに近い位置づけです。

## まず覚えたい基本の操作

| 操作 | Windows | Mac |
|---|---|---|
| コピー | Ctrl＋C | Command＋C |
| 切り取り | Ctrl＋X | Command＋X |
| 貼り付け | Ctrl＋V | Command＋V |
| 元に戻す | Ctrl＋Z | Command＋Z |
| すべて選択 | Ctrl＋A | Command＋A |
| 保存 | Ctrl＋S | Command＋S |
| ページ内を検索 | Ctrl＋F | Command＋F |
| 印刷 | Ctrl＋P | Command＋P |

この8つは、文書作成・表計算・ブラウザなど、ほとんどのアプリで共通して使えます。==特に「保存」はこまめに押す習慣をつける==と、急な停止のときもデータを失いにくくなります。データの守り方は[在宅ワークのデータバックアップ](/articles/data-backup-for-remote-work/)でも解説しています。

## ウィンドウ・タブの切り替え

| 操作 | Windows | Mac |
|---|---|---|
| アプリ（ウィンドウ）の切り替え | Alt＋Tab | Command＋Tab |
| ブラウザで新しいタブ | Ctrl＋T | Command＋T |
| タブを閉じる | Ctrl＋W | Command＋W |
| 閉じたタブを開き直す（主なブラウザ） | Ctrl＋Shift＋T | Command＋Shift＋T |
| デスクトップを表示 | Windows＋D | （ミッションコントロール等で操作） |
| ウィンドウを画面の左右に寄せる | Windows＋←／→ | （標準機能・設定はOSのバージョンによる） |

資料を見ながら入力するときは、==アプリの切り替え（Alt／Command＋Tab）==を覚えるだけでも、マウスで画面下のアイコンを探す手間が減ります。2画面以上で作業しているなら、[デュアルモニターの配置と設定](/articles/dual-monitor-setup/)も参考にしてください。

## スクリーンショットとクリップボード

| 操作 | Windows | Mac |
|---|---|---|
| 範囲を選んでスクリーンショット | Windows＋Shift＋S | Shift＋Command＋4 |
| 画面全体のスクリーンショット | PrtScn（設定による） | Shift＋Command＋3 |
| クリップボードの履歴 | Windows＋V | （標準では履歴機能なし） |

Appleのサポート情報では、Shift＋Command＋4を押すとポインタが十字に変わり、ドラッグした範囲を撮影できると説明されています。Windowsの「Windows＋V」で開くクリップボードの履歴は、初めて使うときに機能をオンにする必要があります。

:::point Web会議で役立つ操作
- 画面共有の前に、関係のないウィンドウやタブを閉じる（Ctrl／Command＋W）
- 資料と会議画面をアプリ切り替え（Alt／Command＋Tab）で行き来する
- ミュートの切り替えは会議アプリごとにショートカットが決まっている。使うアプリの設定画面で確認する
:::

## 覚え方のコツ

:::check 無理なく覚えるために
- 1週間に2〜3個だけ選び、付箋に書いてモニターの横に貼る
- 「右クリックメニューを開くたびに、表示されているショートカットを見る」
- よく使うアプリの「ショートカット一覧」を一度だけ眺めておく
- 使わないショートカットは覚えなくてよい
:::

アプリのメニューには、ショートカットキーが横に書かれていることが多くあります。==メニューを開いたついでにキーを確認する==習慣をつけると、自然に覚えていけます。

## よくある失敗

:::warn やりがちなこと
- **一度にたくさん覚えようとする**：すぐ忘れてしまう。よく使う操作から少しずつ
- **WindowsとMacで混乱する**：まずは「Ctrl ⇔ Command」の置き換えだけ意識する
- **Ctrl＋Wでうっかりウィンドウを閉じる**：閉じたタブはCtrl／Command＋Shift＋Tで開き直せる（主なブラウザ）
- **日本語入力の切り替えと重なる**：入力方法の設定によってキーの働きが変わることがある
:::

## よくある質問

### Q. ノートPCでもショートカットキーは同じ？

基本の操作は同じです。ただし、ノートPCではFnキーと組み合わせないと使えないキーがある場合があります（PrtScnやファンクションキーなど）。キーの配置はメーカーや機種によって異なります。

### Q. 自分でショートカットを作れる？

OSの設定や、アプリ・マウス・キーボードの専用ソフトで、よく使う操作をキーに割り当てられる場合があります。まずは標準のショートカットに慣れてから、足りない操作を追加すると混乱しにくくなります。

### Q. 日本語入力でよく使うキーは？

ひらがなを確定前にF7キーで全角カタカナ、F10キーで半角英数字に変換できる機能が、主な日本語入力ソフトに用意されています。使っている日本語入力ソフトによって動きが異なる場合があります。
