:::reader
キーボードを打っていると手首が反って疲れる…。リストレストを置けば楽になる？ずっと手首を乗せたまま打っていいの？
:::

:::writer
リストレストは使い方がとても大切です。**「打っている間は手を浮かせ、手を止めたときに乗せる」**のが基本とされています。選び方とあわせて整理しますね！
:::

キーボードには高さがあるため、机に手首をついたまま打つと、手首が上に反った姿勢になりがちです。リストレストはこの高さの差を埋めるための道具ですが、置き方や使い方を誤ると、かえって手首の一点に負担がかかることがあります。

この記事では、==リストレストの正しい使い方==と、==キーボードの高さに合わせた選び方==をまとめます。

:::summary 忙しい人向け：この記事の結論
1. **打っている間は手を浮かせ、手を止めたときに手のひらの付け根を乗せる**。手首の一点で体重を支えない
2. **高さはキーボードの手前の高さに近いもの**、幅はキーボードと同じくらい
3. **リストレストより先に、キーボードの傾き・机と椅子の高さを見直す**
:::

## リストレストの正しい使い方

米国労働安全衛生局（OSHA）のガイドでは、リストレスト（パームレスト）は休むときに手首ではなく==手のひらの付け根（手根部）が当たるようにする==ことが示されています。コーネル大学の人間工学ガイドでも、キーボードを打つときは手を浮かせ、打つ合間の短い休みにパームサポートに手を置くのがよいとされています。

:::point 使い方のポイント
- 打っている間は、手首を浮かせて前腕から手の甲までをなるべくまっすぐに
- 手を止めたときに、手のひらの付け根（手首より少し先）を乗せる
- 手首の内側の一点を押しつけたまま打たない
- マウス用も同じ。乗せたまま手首だけで動かさず、腕全体で動かす
:::

リストレストに手首を固定したまま打つと、指を動かすために手首を上下左右に曲げる動きが増えることがあります。==リストレストは「休憩台」であって、手首を固定する台ではない==と考えるとわかりやすいでしょう。

## リストレストを考える前に見直すこと

手首の負担は、キーボードの傾きや机・椅子の高さでも大きく変わります。リストレストを買う前に、次の点を確認しましょう。

:::check 先に見直したいこと
- キーボードの奥側を上げる脚（チルトスタンド）を立てていないか。立てると手首が反りやすい
- 肘がおよそ90度で、キーボードが肘の高さ前後にあるか
- キーボードを体の正面に置き、手首を左右に曲げずに打てるか
- マウスがキーボードから離れすぎていないか
:::

キーボードの高さと傾きの選び方は[在宅ワーク向けキーボードの選び方](/articles/keyboard-for-remote-work/)、机と椅子の高さは[在宅ワークで疲れないデスク環境の作り方](/articles/home-office-setup-basics/)で解説しています。

## 選び方のポイント

| 項目 | 目安・ポイント |
|---|---|
| 高さ | キーボードの手前（スペースキー付近）の高さに近いもの。高すぎると手首が下に曲がる |
| 幅 | キーボードの幅に合わせる。テンキーなしなら30〜35cm、フルサイズなら45cm前後 |
| 奥行き | 手のひらの付け根が乗る程度。浅すぎると手首側にずれやすい |
| 素材 | ジェル、低反発ウレタン、木製など。柔らかさと沈み込みのバランスで選ぶ |
| 表面 | 汗をかきやすいなら、拭けるレザー調や通気性のある布 |
| 裏面 | 滑り止め。打鍵中にずれないもの |

| 素材 | よいところ | 気をつけたいところ |
|---|---|---|
| ジェル | 柔らかく手になじむ | 夏は蒸れやすいことがある |
| 低反発ウレタン | 沈み込んで面で支える | 沈みすぎると高さが足りなくなることがある |
| 木製 | 汚れにくく、高さが変わらない | 硬いので、長く乗せると当たりが気になることがある |

## マウス用リストレストの考え方

マウス用のリストレストも、手首を固定して手首だけで操作するための台ではありません。マウスは腕全体を使って動かし、手を止めたときに手のひらを休ませる使い方が基本です。

手首の向きそのものが気になる場合は、縦型マウスやトラックボールを検討するのもひとつの方法です。詳しくは[手首が痛い人のためのマウス選び](/articles/ergonomic-mouse-vertical/)をご覧ください。

:::warn 痛みが続くときは
手首の痛みやしびれ、指の感覚の違和感が続く場合は、道具で対処しようとせず、早めに医療機関に相談してください。この記事の内容は一般的な情報で、治療の代わりにはなりません。
:::

## よくある失敗

:::warn やりがちなこと
- **手首を乗せたまま打ち続ける**：打つときは浮かせ、休むときに乗せる
- **高すぎるリストレストを選ぶ**：手首が下に曲がる。キーボードの手前の高さに合わせる
- **キーボードの脚を立てたまま使う**：手首が反りやすい。脚をたたんでから試す
- **幅が足りない**：キーボードの幅に合わせる
:::

## よくある質問

### Q. リストレストは使わないほうがいい？

使い方しだいです。手首をついたまま打つ習慣があるなら、リストレストで高さの差を埋めると手首が反りにくくなります。ただし、手首を押しつけたまま打つのは避け、休むときに使うようにしましょう。

### Q. タオルを丸めて代用してもいい？

高さの確認には使えますが、つぶれたり位置がずれたりしやすいので、長く使うなら専用品がおすすめです。

### Q. ノートPCでもリストレストは必要？

ノートPCは本体の手前に手を置けるので、外付けのリストレストは必要ない場合が多いです。ノートPCで手首や首がつらい場合は、外付けキーボードとPCスタンドの組み合わせを検討しましょう。詳しくは[ノートPCで首が痛い人へ](/articles/laptop-stand-external-keyboard/)をご覧ください。

## まとめ

:::summary リストレストの選び方・使い方
- 打つときは浮かせ、手を止めたときに手のひらの付け根を乗せる
- 高さはキーボード手前に近いもの、幅はキーボードに合わせる
- 先にキーボードの傾き・机と椅子の高さを見直す
- 痛みやしびれが続くときは医療機関へ
:::

まずはキーボードの脚をたたみ、肘の高さとキーボードの位置を見直してみてください。そのうえで手を休める場所がほしいと感じたら、リストレストを足すのがおすすめです。
