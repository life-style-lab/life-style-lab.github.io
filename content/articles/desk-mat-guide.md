:::reader
机の天板が冷たいし、マウスを動かす音も気になる…。デスクマットを敷きたいけど、素材もサイズも色々あってどれがいいのかわからない。
:::

:::writer
デスクマットは**「何を上に置くか」でサイズが、「何に困っているか」で素材が決まります**。選び方の順番と、買ってから後悔しやすいポイントを整理しますね！
:::

デスクマットは、天板の傷や汚れを防ぐだけでなく、手首が当たったときの冷たさを和らげたり、マウスの操作感やキーボードの打鍵音を変えたりと、作業のしやすさにも関わります。

この記事では、==素材ごとの向き・不向き==と、==キーボードとマウスが収まるサイズの測り方==をまとめます。

:::summary 忙しい人向け：この記事の結論
1. **サイズは「キーボード＋マウスの可動範囲」が収まる幅が基本**。目安は幅80〜90cm×奥行き30〜40cm
2. **素材は困りごとで選ぶ**。冷たさ・音ならフェルト、汚れやすさならPUレザーや塩ビ
3. **天板の素材・塗装との相性に注意**。熱いもの・直射日光・長期間の敷きっぱなしは変色や跡の原因になることがある
:::

## デスクマットで変わること

| 困りごと | デスクマットの役割 |
|---|---|
| 天板が冷たい・硬い | 手首や前腕が当たる部分の冷たさや硬さを和らげる |
| マウスの動きが不安定 | 表面がそろい、マウスの読み取りや滑りが安定しやすい |
| 打鍵音・マウスの音が響く | 柔らかい素材なら机に伝わる音を抑えやすい |
| 天板の傷・汚れ | 飲みこぼしやペンの跡から天板を守る |
| 光沢のある天板がまぶしい | つや消しの表面なら照明の反射を抑えやすい |

厚生労働省の情報機器作業ガイドラインでは、まぶしさ（グレア）を防ぐことが作業環境の管理項目に挙げられています。==光沢のある天板で照明が反射して気になる場合は、つや消しのマットを敷く==のもひとつの方法です。

## サイズの選び方

| サイズの目安（幅×奥行き） | 向いている使い方 |
|---|---|
| 30×25cm前後 | マウスだけ（マウスパッドとして） |
| 60×30cm前後 | テンキーなしキーボード＋マウス |
| 80〜90×30〜40cm | フルサイズキーボード＋マウス、メモ帳も置きたい |
| 机の幅いっぱい | ノートPCや書類も含めて天板全体を覆いたい |

==奥行きは、キーボードの手前で手首や前腕を置ける余裕があるか==で決めるのがおすすめです。奥行きが浅いと、マットの縁がちょうど手首に当たって気になることがあります。

:::check 買う前に測ること
- キーボードの幅と、マウスを左右に動かす範囲
- 机の奥行きと、モニターの台座の位置（マットに台座が乗るか）
- 机の手前の縁からキーボードまでの距離
- 昇降デスクやモニターアームのクランプと干渉しないか
:::

## 素材ごとの特徴

| 素材 | よいところ | 気をつけたいところ |
|---|---|---|
| フェルト | 手触りが柔らかく冷たさを感じにくい。音が響きにくい | 飲みこぼしが染みやすい。毛羽立ちやほこりが付きやすい |
| PUレザー（合成皮革） | 汚れを拭き取りやすい。見た目が落ち着いている | 長く使うと表面がはがれることがある。熱に弱い製品も |
| 布（ゲーミング系マウスパッドの大判） | マウスが滑りやすく、読み取りが安定しやすい | 汚れを落とすには洗う必要がある |
| 透明な塩ビ（PVC） | 天板の見た目を生かせる。下にメモを挟める | 熱いものを置くと変形することがある。天板の塗装との相性に注意 |
| コルク | 自然素材の手触り。冷たさを感じにくい | 表面が削れやすく、汚れが染みやすい |

## マウスの読み取りとの相性

マウスは、底面のセンサーで机の表面の模様や凹凸を読み取って動きを検出します。そのため、==表面がつるつるで均一すぎる素材や、透明な素材の上では読み取りにくい==ことがあります。

| マットの表面 | マウスとの相性 |
|---|---|
| 布・フェルト | 一般的に読み取りやすい |
| PUレザー | 多くのマウスで問題なく使えるが、表面の質感による |
| 透明な塩ビ・ガラス | 一般的なマウスでは読み取りにくいことがある |

ガラスの上でも使えることをうたうセンサーを積んだマウスもありますが、一般的な光学式マウスを使うなら、布やフェルトの部分にマウスを置くほうが安心です。マウスの選び方は[エルゴノミクスマウスの選び方](/articles/ergonomic-mouse-vertical/)でも解説しています。

## 天板を傷めないための注意点

:::warn 敷きっぱなしで起きやすいこと
- **変色・跡**：高温多湿や直射日光の当たる場所に長く敷いたままにすると、マットや天板が変色したり反ったりすることがある
- **熱による変形**：塩ビなど熱に弱い素材の上に、熱い飲み物のカップを直接置かない
- **天板への密着**：ガラスや鏡面仕上げの天板では、マットが張り付くことがある
- **塗装のはがれ**：塗装の弱い天板では、マットをはがすときに塗装がはがれることがある
:::

天板の素材や塗装に不安があるときは、家具メーカーの取扱説明書を確認しましょう。==ときどきマットを外して、天板とマットの裏を乾かす==と、湿気がこもりにくくなります。

## よくある失敗

:::warn 買ってから気づきやすいポイント
- **小さすぎてマウスがはみ出す**：マウスを動かす範囲まで含めて幅を決める
- **縁が手首に当たる**：奥行きに余裕のあるサイズを選ぶ
- **丸めて届いた跡が戻らない**：平らな場所でしばらく置くか、重しをのせて伸ばす
- **フェルトに飲み物をこぼす**：飲み物はマットの外に置く習慣をつける
:::

## よくある質問

### Q. デスクマットとマウスパッドは別々に必要？

大判のデスクマットなら、マウスパッドを兼ねられます。ただし、マットの表面がマウスに合わない場合は、マットの上に小さなマウスパッドを重ねる方法もあります。

### Q. 透明マットの下にメモや予定表を挟みたい

透明な塩ビのマットなら、下に紙を挟めます。ただし、紙の印刷が長期間でマットに写ることがあるため、写り防止の加工がある製品を選ぶと安心です。

### Q. 昇降デスクにも使える？

使えます。天板が上下してもずれにくいよう、裏面が滑り止めのものを選びましょう。昇降デスクの選び方は[電動昇降デスクの選び方](/articles/standing-desk-how-to-choose/)をご覧ください。

## まとめ

:::summary デスクマットの選び方のポイント
- サイズはキーボード＋マウスの可動範囲で決める（目安：幅80〜90×奥行き30〜40cm）
- 冷たさ・音ならフェルト、汚れやすさならPUレザーや塩ビ
- 透明・つるつるの表面ではマウスが読み取りにくいことがある
- 熱いもの・直射日光・敷きっぱなしの湿気に注意
:::

まずはキーボードとマウスを普段どおりに置いて、必要な幅と奥行きをメジャーで測ってみてください。サイズが決まれば、あとは困りごとに合わせて素材を選ぶだけです。
