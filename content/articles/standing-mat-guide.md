:::reader
昇降デスクを買って立って作業するようにしたら、30分もすると足の裏やふくらはぎが疲れてくる…。立ち作業用のマットって効果あるの？
:::

:::writer
硬い床に立ち続けると、足が疲れやすくなります。マットはその負担を和らげる道具ですが、**「立ちっぱなしにしない」工夫とセットで使う**のがポイントです。選び方と使い方を整理しますね！
:::

スタンディングデスクは座りっぱなしを減らすのに役立ちますが、今度は「立ちっぱなし」になると、足の裏やふくらはぎ、腰に負担がかかります。特にフローリングなど硬い床では、疲れを感じやすくなります。

この記事では、==疲労軽減マットでできること・できないこと==と、==マットを選ぶときのチェックポイント、立ち作業の続け方==をまとめます。

:::summary 忙しい人向け：この記事の結論
1. **疲労軽減マットは「硬い床で立つ疲れ」を和らげる道具**。単体では足の疲れを解消しきれない
2. **選ぶなら厚さ1.5〜2cm前後、縁が斜めのもの**。厚すぎるとふらつき、縁が立っているとつまずきやすい
3. **立ちっぱなしにしない**。座る・立つをこまめに切り替え、立っている間も足の位置を変える
:::

## 立ち作業で疲れる理由

| 原因 | 起きやすいこと |
|---|---|
| 硬い床に立ち続ける | 足の裏やかかとに負担が集中する |
| 同じ姿勢で動かない | ふくらはぎや腰の筋肉が緊張し続ける |
| 机の高さが合っていない | 肩が上がる、前かがみになる |
| 靴を履かず素足・靴下 | 足裏のクッションがなく、負担が直接かかる |

カナダ労働安全衛生センター（CCOHS）は、疲労軽減マットを「硬い床に長時間立つことによる疲れを減らすためのマット」と説明しています。一方で、==マットや床のカーペットだけで足の痛みがなくなるわけではなく、作業の仕方や履物の工夫と組み合わせることで作業環境が改善する==としています。

| チェック項目 | 目安・ポイント |
|---|---|
| 厚さ | 1.5〜2cm前後の製品が多い。厚すぎると足元が不安定になることがある |
| 素材 | ゴム、ジェル入りのフォーム、ウレタンなど。適度な弾力があり、沈み込みすぎないもの |
| 縁の形 | 斜めにカットされたもの。縁が立っているとつまずきやすい |
| 裏面 | 滑り止め加工。フローリングでずれにくいもの |
| サイズ | 両足を肩幅に開き、少し足の位置を変えられる広さ（目安：幅60cm前後〜） |
| 耐熱・耐水 | 床暖房や飲みこぼしがあるなら確認 |

CCOHSは、マットは置き方を誤るとつまずきや転倒の原因になることがあるとして、注意を呼びかけています。==縁が斜めになっていて、床にぴったり沿うもの==を選び、めくれていないか定期的に確認しましょう。

## 立ち作業を続けるコツ

マットを敷いても、長時間同じ姿勢で立ち続ければ疲れはたまります。==座る・立つをこまめに切り替える==ことが、何より大切です。

:::point 立ち作業のポイント
- 立つ時間は短めから始め、疲れる前に座る（例：30分〜1時間ごとに切り替える）
- 机の高さは、立ったときの肘の高さ前後に合わせる
- 低い台や足置きに片足を乗せ、ときどき左右を入れ替える
- 体重を片足にかけ続けない。足の位置をときどき変える
- 室内履きなど、足裏にクッションのある履物を検討する
:::

厚生労働省の情報機器作業ガイドラインでも、同じ姿勢を長時間続けないことや、作業の合間に休止を設けることが示されています。立つ・座るの切り替えや、昇降デスクの高さの目安は[電動昇降デスクの選び方](/articles/standing-desk-how-to-choose/)で詳しく解説しています。

:::warn こんなときは無理をしない
足の痛みが続く、しびれがある、むくみが強いといった場合は、立ち作業の時間を減らし、医療機関に相談してください。
:::

## マット以外の選択肢

| 選択肢 | 特徴 | 向いている人 |
|---|---|---|
| 室内履き・クッション性のある靴 | 足裏全体を支え、マットのない場所でも使える | 部屋の中を移動しながら作業する人 |
| ラグ・カーペット | 部屋全体の床を柔らかくできる | マットの縁が気になる人。キャスター付き椅子との相性に注意 |
| バランスボード・ロッキングボード | 足を動かしながら立てる | じっと立つのが苦手な人。慣れるまで転倒に注意 |
| 低い足置き台 | 片足を乗せて体重を移せる | 腰の疲れが気になる人 |

足置き台の選び方は[フットレストの選び方](/articles/footrest-guide/)も参考にしてください。

## よくある失敗

:::warn やりがちなこと
- **厚くて柔らかすぎるマットでふらつく**：適度な弾力のものを選ぶ
- **座るときに椅子のキャスターがマットに乗る**：座る位置とマットの位置を分ける
- **マットの縁につまずく**：縁が斜めのものを選び、めくれを直す
- **マットがあるからと長時間立ちっぱなし**：時間を決めて座る
:::

## よくある質問

### Q. 立ち作業は1日どれくらいがいい？

決まった正解はなく、体調や作業内容によって異なります。最初は短い時間から始め、疲れを感じる前に座るようにしましょう。大切なのは、座る・立つを切り替えて同じ姿勢を続けないことです。

### Q. ヨガマットで代用できる？

ヨガマットは薄くて柔らかいものが多く、立ち作業用としてはクッション性が足りなかったり、縁がめくれやすかったりすることがあります。代用する場合は、つまずかないよう端の処理に注意しましょう。

### Q. 素足で立つのはだめ？

素足や靴下だけで硬い床に立つと、足裏に負担が集中しやすくなります。マットを使うか、クッション性のある室内履きを検討しましょう。

## まとめ

:::summary 立ち作業用マットのポイント
- マットは硬い床で立つ疲れを和らげる道具。単体では疲れを解消しきれない
- 厚さ1.5〜2cm前後、縁が斜め、裏面が滑りにくいものを選ぶ
- 座る・立つをこまめに切り替え、立っている間も足の位置を変える
- 足の痛みやしびれが続くときは無理をしない
:::

まずは立つ時間を短めに決めて、疲れを感じる前に座る習慣から始めてみてください。それでも足が疲れるなら、マットや室内履きを足していくのがおすすめです。
